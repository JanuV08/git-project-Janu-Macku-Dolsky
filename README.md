# Webová stránka o nás

## Krátký popis

Jednoduchá webová stránka vytvořená jako společný školní projekt. Stránka představuje členy našeho týmu, jejich role a způsob, jakým na projektu spolupracujeme.

## Co jsme vytvořili

Web je vytvořen jako přehledná jednostránková prezentace týmu. Návštěvník na něm najde:

- úvodní představení týmu,
- informace o autorech projektu,
- rozdělení práce mezi členy,
- popis našeho pracovního postupu,
- základní informace o použitých nástrojích.

Stránka je responzivní, takže se přizpůsobí počítači i mobilnímu zařízení. Vizuální styl používá zelenou barevnou paletu, výraznou úvodní část a bloky připomínající terminál, které odkazují na vývojářské prostředí.

## Návod k instalaci a spuštění

### Spuštění bez instalace

1. Stáhněte nebo naklonujte tento repozitář.
2. Otevřete soubor `index.html` ve webovém prohlížeči.
3. Procházejte stránku pomocí horní navigace nebo posouváním dolů.

Projekt nevyžaduje instalaci balíčků ani spuštění serveru.

### Spuštění přes Visual Studio Code

1. Otevřete složku projektu ve Visual Studio Code.
2. Otevřete soubor `index.html`.
3. Spusťte ho pomocí rozšíření Live Server, případně klikněte pravým tlačítkem na soubor a zvolte otevření v prohlížeči.

## Ukázka výstupu

Po otevření stránky se zobrazí úvodní nadpis a představení týmu:

```text
Tvoříme společně.

Jsme tři vývojáři, které spojuje zájem o technologie,
kreativní řešení a práce na společném projektu.
```

Ukázka části zdrojového kódu, která vytváří odkaz na představení týmu:

```html
<a class="button" href="#tym">Poznat náš tým</a>
```

## Pracovní postup týmu

Na projektu postupujeme ve čtyřech krocích:

1. **Domluvíme se** - rozdělíme si úkoly a stanovíme společný směr.
2. **Tvoříme** - každý pracuje na své části projektu.
3. **Kontrolujeme** - vzájemně si prohlédneme změny a hledáme možnosti zlepšení.
4. **Dokončíme** - spojíme jednotlivé části do jednoho funkčního výsledku.
